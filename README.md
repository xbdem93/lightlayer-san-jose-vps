## 圣何塞的线路到底怎么分层

圣何塞到国内快，这是地理决定的。真正决定你晚上八点到十点能不能顺畅用的，是回程走哪条骨干。

**CN2 GIA（AS4809）** 是电信的高端承载网，走 59.43 节点。V.PS 那台 SJC Starter 的电信回程实测路径是 AS4134 接 AS4809，北京落地 146–150ms，广东 164ms 左右。这条线贵，但晚高峰的丢包和抖动控制得最好。

**AS9929（联通 CUII）** 是联通的精品网。同一台机器的联通回程走 AS10099 到 AS9929，北京 161ms 上下。

**CMIN2（AS58807）** 是移动的国际精品线路。V.PS 的移动回程走 AS58807，上海 125ms、北京 154ms、广东 161ms，比 2024 年那批走普通 CMI 的机器（移动回程 185–220ms）强一大截。

**普通国际直连** 是三网各走各的骨干，不做专项优化。DMIT SJC 在 2023 年 4 月之后就是这个状态，电信 CT163、联通 CU169、移动 CMI，延迟 150–170ms。数字上和优化线路差不太多，差在拥塞时段的稳定性，这是普通国际线路的通病。

把三家放在一起看：V.PS 是电信 CN2 GIA + 联通 9929 + 移动 CMIN2 的三网全优化；NoslaCloud 是电信 CN2（AS4134 经上海）+ 联通 AS9929 到 AS10099 + 移动 CMI（AS58807）；DMIT SJC 现在是纯直连。

LightLayer 的 Premium 系列官方描述是「CN2 优化线路」，具体三网分别落到哪个 AS、去程回程是否对称，公开资料里没有 traceroute 可查。这不是能靠猜补上的信息，下单前用商家提供的测试 IP 或者最低档月付机器跑一遍去回程路由，比看任何宣传文案都准。想自己验线路，从最便宜那档入手成本最低。

## 常见问题

**300Mbps 和 1Gbps 实际差多少？**

300Mbps 跑满约 37.5MB/s，1Gbps 约 125MB/s。单线程下载和普通建站首屏感受不到这个差距，瓶颈通常在对面服务器和回国链路。跑大文件传输、多并发、做中转，差距就出来了。

**500GB 月流量够不够用？**

日常 SSH、轻量代理、个人博客，一个月几 GB 到几十 GB，500GB 富余很多。跑视频中转、远程桌面、网盘同步，或者流量按双向计费，500GB 会紧张。先估一下自己每月上下行合计多少，再决定要不要为 1TB 多付 5 美元。

**LightLayer 的机器能解锁 Netflix 吗？**

没有公开实测数据。同上游的 V.PS 和 NoslaCloud 实测都是 Netflix 仅自制、Disney+ 和 Reddit 屏蔽。需要流媒体解锁的话，买之前先要测试 IP 验证，别按宣传页面推断。

**买完不满意能退吗？**

LightLayer 的退款条款公开资料里查不到。同类商家里，V.PS 是 14 天内可申请（有条件），DMIT 是 3 天内且流量不超 30GB 全额退，AkkoCloud 不支持退款。下单前问客服要一份书面条款，比事后扯皮省事。

**以后配置不够能升级吗？**

可以，LITE 最高能升到 2 核 2GB，SJ-VP04-L 也支持配置升级。升级时的差价怎么算、要不要重装系统，问客服确认。
